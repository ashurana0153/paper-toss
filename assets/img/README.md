# Optional artwork

Drop a photo or render here and the game uses it instead of the drawn scene:

- `office.jpg` – a 16:9 picture of an office or room with an open floor (about 1920 x 1080). It is cover-fitted behind the game.
- `bin.png` – a transparent PNG of a bin seen slightly from above. The rim should span about 98% of the image width and the base should sit about 92% of the way down.

Both files are optional. Without them the game draws its own scene and bin.
